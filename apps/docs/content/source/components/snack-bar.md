# 스낵바

상태: 진행 중

## 01. 컴포넌트 용도 (Purpose)

SnackBar는 사용자 행동의 결과나 일시적인 피드백을 짧은 메시지로 전달하는 컴포넌트예요.

- 저장, 복사, 삭제 등 사용자가 수행한 작업의 결과를 안내할 때 사용해요.
- 메시지와 함께 사용자가 선택할 수 있는 후속 행동을 제공할 때 적합해요.
- 별도의 상태 아이콘 없이 간결한 텍스트 중심으로 피드백을 전달해요.
- 메시지는 최대 두 줄까지 표시할 수 있어요.

## 02. 컴포넌트 구조 (Structure)

SnackBar는 메시지 영역과 선택적인 액션 버튼으로 구성돼요.

- **Message**: 사용자에게 전달할 피드백 메시지를 표시해요.
- **Action**: 메시지와 관련된 후속 행동을 실행하는 버튼이에요.

구성 규칙은 다음과 같아요.

- 메시지는 필수 표시 요소이며, 생략하면 기본 메시지가 표시돼요.
- 액션 버튼은 기본적으로 표시되며, `action`에 `null`을 전달하면 숨길 수 있어요.
- 액션 버튼을 표시하지 않는 경우 메시지만으로 구성돼요.
- 별도의 상태 아이콘이나 제목 영역은 제공하지 않아요.

## 03. 프로퍼티 (Properties)

### Variant

별도의 Variant Props는 제공하지 않아요.

### Size

별도의 Size Props는 제공하지 않아요.

### State

별도의 State Props는 제공하지 않아요.

### 기타 Props

| Prop | 타입 | 기본값 | 설명 |
| --- | --- | --- | --- |
| `children` | `ReactNode` | `메시지를 작성합니다.` | SnackBar에 표시할 메시지예요. |
| `action` | `ReactNode` | `액션` | 오른쪽 액션 버튼에 표시할 내용이에요. |
| `actionColor` | `CSSProperties['color']` | - | 액션 버튼의 글자 색상을 지정해요. |
| `onAction` | `MouseEventHandler<HTMLButtonElement>` | - | 액션 버튼을 클릭했을 때 실행할 함수예요. |
| `className` | `string` | - | 루트 요소에 추가할 CSS 클래스예요. |

그 외에 `id`, `style`, `role` 등 HTML `div` 요소의 속성을 전달할 수 있어요. `children`은 별도 Props로 정의되므로 HTML 속성 상속에서는 제외돼요.

### 프로퍼티 조합

- `children`을 생략하면 기본 메시지인 `메시지를 작성합니다.`가 표시돼요.
- `action`을 생략하거나 `undefined`로 전달하면 기본값인 `액션`이 표시돼요.
- `action`에 `null`을 전달하면 액션 버튼이 표시되지 않아요.
- `actionColor`는 액션 버튼의 글자 색상에만 적용돼요.
- `onAction`은 액션 버튼이 표시될 때 해당 버튼의 클릭 이벤트를 처리해요.
- `onAction`을 전달하지 않아도 액션 버튼은 표시돼요. 다만 클릭해도 별도의 동작은 실행되지 않아요.

## 04. 인터랙션 규칙 (Interaction)

### 메시지 표시

- `children`으로 전달한 내용을 메시지 영역에 표시해요.
- 메시지가 길어지면 최대 두 줄까지 표시하고 이후 내용은 잘라서 보여줘요.
- 메시지는 ReactNode를 지원하므로 문자열 외에도 React 요소를 전달할 수 있어요.

### 액션 버튼

- `action`으로 전달한 내용을 버튼에 표시해요.
- 버튼을 클릭하면 `onAction`에 전달한 함수가 실행돼요.
- `onAction`은 버튼의 클릭 이벤트를 인자로 전달받아요.
- 액션 버튼은 `type="button"`으로 동작하므로 폼 제출을 실행하지 않아요.
- `action`에 `null`을 전달하면 버튼과 클릭 영역이 함께 사라져요.

### 예외 상황 및 제한 사항

- 자동으로 표시되거나 사라지는 타이머는 구현되어 있지 않아요.
- 닫기 버튼이나 별도의 닫기 이벤트는 제공하지 않아요.
- 화면 내 표시 위치나 등장·퇴장 애니메이션을 자체적으로 제어하지 않아요.
- 메시지의 표시 시간과 SnackBar의 제거 시점은 사용하는 쪽에서 관리해야 해요.
- 액션 버튼의 비활성화 상태를 제어하는 별도 Props는 제공하지 않아요.
- `action`이 표시되더라도 `onAction`을 전달하지 않으면 클릭에 따른 기능은 실행되지 않아요.

## 05. 사용 가이드 (Usage Guidelines)

### Do

- 사용자가 수행한 작업의 결과를 간결하게 전달해요.
- 메시지에는 작업 결과를 명확하게 작성해요.
- 후속 행동이 필요한 경우 `action`과 `onAction`을 함께 제공해요.
- 후속 행동이 필요하지 않다면 `action={null}`로 메시지만 표시해요.
- 액션 버튼에는 실행할 행동을 명확하게 표현하는 텍스트를 사용해요.
- 메시지와 액션이 서로 직접적으로 연결되도록 구성해요.

### Don't

- 장시간 확인해야 하는 중요 안내나 지속적으로 노출되어야 하는 오류에 사용하지 않아요.
- 긴 설명이나 여러 정보를 한 번에 전달하는 용도로 사용하지 않아요.
- 액션 버튼을 제공하면서 `onAction`을 누락하지 않도록 해요.
- 사용자가 반드시 확인해야 하는 경고를 SnackBar만으로 전달하지 않아요.
- 액션 버튼에 메시지와 관련 없는 행동을 배치하지 않아요.

### Alternative

- 사용자가 내용을 확인할 때까지 유지해야 하는 안내라면 Alert를 사용해요.
- 성공, 오류, 주의, 정보 등 상태에 따른 아이콘과 설명이 필요한 경우 Alert를 사용해요.
- 개별 입력 항목의 오류를 안내해야 한다면 TextField의 `error` 상태를 사용해요.

### Reason

SnackBar는 작업 결과를 간결하게 전달하고 필요한 경우 즉각적인 후속 행동을 제공하는 데 적합해요. 반면 사용자가 반드시 확인해야 하는 안내나 자세한 설명이 필요한 상황에서는 메시지가 일시적인 피드백으로 소비되지 않도록 Alert와 같은 별도의 안내 컴포넌트를 사용하는 것이 적절해요.

## 06. 추천 조합 (Composition)

### Button + SnackBar

사용자가 버튼을 통해 작업을 실행한 뒤 그 결과를 피드백으로 전달할 때 함께 사용해요.

| 컴포넌트 | 역할 | 사용 예시 |
| --- | --- | --- |
| Button | 사용자의 작업을 실행해요. | 저장, 복사, 삭제 |
| SnackBar | 작업 결과를 전달하고 후속 행동을 제공해요. | 저장 완료, 복사 완료, 실행 취소 |

**사용 예시**

- 복사 Button을 클릭하면 `복사했어요.` 메시지를 표시해요.
- 삭제 Button을 클릭하면 `항목을 삭제했어요.` 메시지와 `실행 취소` 액션을 제공해요.
- 저장 Button을 클릭하면 `변경 사항을 저장했어요.` 메시지를 표시해요.

**조합 규칙**

- Button은 작업을 실행하고 SnackBar는 실행 결과를 전달해요.
- 작업이 완료된 이후 결과에 맞는 메시지를 표시해요.
- 되돌리기 등 후속 행동이 필요한 경우 `action`과 `onAction`을 연결해요.
- SnackBar의 액션은 메시지와 관련된 행동으로 구성해요.

### IconButton + SnackBar

아이콘 버튼으로 실행한 행동의 결과를 텍스트로 안내할 때 함께 사용해요.

| 컴포넌트 | 역할 | 사용 예시 |
| --- | --- | --- |
| IconButton | 아이콘을 통해 행동을 실행해요. | 링크 복사, 즐겨찾기, 항목 삭제 |
| SnackBar | 실행 결과를 텍스트로 안내해요. | 링크를 복사했어요, 즐겨찾기에 추가했어요 |

**조합 규칙**

- IconButton은 행동을 실행하고 SnackBar는 실행 결과를 설명해요.
- 아이콘만으로 전달하기 어려운 작업 결과를 SnackBar의 메시지로 보완해요.
- 액션 버튼을 제공한다면 실행 결과와 직접 연결되는 행동을 배치해요.
