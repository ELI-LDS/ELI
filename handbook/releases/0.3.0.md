# CLI 0.3.0 게시 대기 · UI 콘텐츠 0.2.0 공개

2026년 11월 23일 UI 콘텐츠 공개와 CLI 고정 파일 검증·전달 준비를 완료했어요. CLI 0.3.0은 아직 npm에 게시하지 않았어요. **저장소 이전 후에는 아래 파일의 게시를 보류해요.** 고정 파일에 이전 Release API 주소가 남아 있고 이전 API가 301로 응답하는 것을 확인했어요. 아래는 이전 시점의 검증 기록이며, 수정한 새 CLI 후보를 검증해 별도 전달하기 전까지 게시 준비 완료로 보지 않아요. 기존 파일·태그·해시는 보존해요.

## 최종 후보 검증

아래 검사는 위 원본 커밋과 고정한 후보에서 실행했어요.

- Node.js 24.21.0·pnpm 12.8.1의 frozen 설치, `pnpm check` 통과. 타입·린트·Storybook·tarball 소비·Chromium·Next.js·UI 패키지 자체 크기를 확인했어요.
- `pnpm test:registry` 통과: 규격·의존성·해시 테스트 8개, 전체 소스 타입·Vite·CSS, 대표 Next.js SSR·hydration 검사.
- `pnpm test:cli` 28개 통과. 이 소스 검사는 현재 하네스 원본도 포함하므로, 배포에 재사용한 공개 하네스는 아래에서 별도로 검사했어요.
- 같은 최종 CLI tarball로 npm 11.19.0·pnpm 12.8.1·Yarn Classic 1.22.22·Yarn Modern 4.18.1 node-modules/PnP·Bun 1.4.4의 실행·타입·Vite·CSS·SSR·프로젝트 설정 보존 통과.
- 같은 SHA의 [브라우저 7종 CI](https://github.com/ELI-team/ELI/actions/runs/45111322178) 통과: Chromium·Chrome·Edge·Firefox·WebKit·Android Chromium·iOS WebKit 조건.
- 최종 tarball을 저장소 밖에 실제 설치한 뒤, 그 실행 파일로 로컬 스냅샷과 공개 UI JSON 각각의 전체 소스 타입·Vite·CSS와 대표 Next.js SSR·hydration·Modal/TextField 동작을 확인했어요.
- 공개 기본 콘텐츠 탐색·개별/조합/전체 34개 추가·공유 파일 재사용·수정 파일 보호 통과. 공개 하네스 0.1.0의 설치·기존 설정 보존·재실행·일반/JSON status·로컬 소스 훅 인식도 확인했어요.

Vite 소비 빌드의 `'use client'` 경고와 Yarn PnP 권장 여부 경고는 남아 있어요. 타입·SSR·Next.js의 Client Component 경계 검사를 함께 통과했으며 경고를 숨기는 설정은 추가하지 않았어요.

2026-11-23 GitHub의 열린 보안 경고 24개도 확인했어요. 대상은 Storybook·Vite·glob·minimatch이고, 이 CLI의 유일한 실행 의존성인 semver에는 현재 경고가 없어요. Storybook에는 Critical, Vite에는 High 경고가 있어 개발 도구 보안 업데이트를 별도 작업으로 진행해야 해요. 이 도구들은 CLI tarball이나 선택 UI 소스에 포함되지 않으며, 이번 소비 검사 통과가 저장소 보안 검토 전체의 완료를 뜻하지 않아요.

위 내용은 고정한 배포 원본의 진단 기록이에요. 이후 개발 도구 보안 수정은 [CHANGELOG의 Unreleased](../../CHANGELOG.md#unreleased)에서 별도로 관리해요. 수정 후에도 이 릴리스의 고정 파일·태그를 다시 만들지 않아요.

### 다운로드량

같은 CLI SHA-256과 공개 UI·하네스 바이트를 격리 로컬 HTTP 서버에서 측정했어요. React 19.3.0이 준비된 앱이 조건이며 공개 npm/CDN의 실측값은 아니에요. 아래는 JSON에 gzip을 적용한 응답 본문 합계예요.

| 선택 | 첫 실행·빈 캐시 | 도구 캐시 재사용·같은 명령 재실행 |
| --- | ---: | ---: |
| Button | 110,935 B | 12,711 B |
| Modal | 117,564 B | 19,340 B |
| Button → Modal → Select | 146,519 B | 48,295 B |
| 전체 컴포넌트 | 209,086 B | 110,862 B |

첫 실행은 설치 도구·semver·메타데이터·선택 UI JSON을 합산해요. HTTP 헤더·TLS·TCP·기존 React와 개발 도구 준비 비용은 제외해요. 무압축 조건과 하네스 포함 시나리오, 도구 버전·환경·전체 행렬은 전달한 `release.json`에 기록했어요. 기존 UI tarball 자체 크기는 압축 120,562 B·압축 해제 462,187 B·317개 파일이며 소스 설치 다운로드량과 구분해요.

## 준비 브랜치 사전 확인

고정 Node.js 24.21.0·pnpm 12.8.1에서 lockfile 동기화와 frozen 설치, 타입·린트, CLI 테스트 28개와 레지스트리 테스트 8개를 확인했어요. 최종 병합 SHA·tarball의 검사와는 구분해요.

재사용할 공개 하네스 0.1.0을 익명 다운로드하고 내부 파일 해시를 확인했어요. 원본 JSON의 SHA-256은 `f034ddf934b97f59cb7cef0575bd0ef7b22caeb6b94525eb34111740e2144efd`예요. 최종 CLI의 공개 하네스 소비 검증은 후보 고정 후에 진행해요.

## 게시 경계

UI 공개와 CLI 파일 전달은 완료했지만 npm 0.3.0 게시·공개 npm 명령·latest 승격은 아직 진행하지 않았어요. npm 담당자는 [게시 안내](../npm-publishing.md)에 따라 고정 파일을 next로 게시하고 integrity를 전달해요. 준비자가 공개 명령을 검증한 뒤 담당자가 latest로 전환해요.

실제 macOS Safari 앱·Android/iOS 기기, VoiceOver, 에이전트의 스킬 수행·훅 신뢰와 원격 MCP는 별도 검증 범위예요. 자동 Android·iOS 결과는 에뮬레이션이에요. 기존 axe 색상 대비 기준선 14개는 디자이너 검토 대상으로 남아 있으며 접근성 전체 통과로 표현하지 않아요.
