# CLI 0.3.1 준비 — npm 미게시

이 문서는 다음 설치 도구의 준비 상태를 기록해요. 아직 최종 후보를 고정하거나 npm에 게시하지 않았어요. 완료한 검사와 고정 파일은 실제 검증 후 갱신해요.

## 대상과 범위

| 대상 | 버전 | 상태 |
| --- | --- | --- |
| 설치 도구 eli-design | 0.3.1 | 준비 중, npm 미게시 |
| UI 소스 콘텐츠 | 0.2.0 | 기존 공개 v0.2.0 JSON을 재사용 |
| 하네스 콘텐츠 | 0.1.0 | 기존 공개 harness-v0.1.0 JSON을 재사용 |

- [#99](https://github.com/ELI-team/ELI/pull/99)의 ELI-team/ELI 주소·공개 도메인 안내와 [#95](https://github.com/ELI-team/ELI/pull/95)의 status 안내 개선을 포함해요.
- 기존 0.3.0 후보의 짧은 소스 경로·기본 설치 위치·충돌 보호를 포함해요. 기존 고정 tarball과 태그는 보존해요.
- UI API 보완 [#100](https://github.com/ELI-team/ELI/pull/100), 미확정 Tooltip·Tab 동작과 하네스 구현은 포함하지 않아요. 새 UI 콘텐츠를 공개하는 릴리스가 아니에요.
- 웹사이트 eli-design.dev는 제작 예정 주소이며, Storybook은 storybook.eli-design.dev예요. 웹페이지·DNS를 구현하는 작업은 포함하지 않아요.

현재 npm latest·next는 0.2.0이에요. 0.3.0 후보 이후 수정은 PATCH에 해당하지만 실제 0.2.0에서 갱신할 때는 기본 설치 위치 변경을 포함하는 MINOR 이전이에요. 기존 eli.json과 설치한 소스는 자동 이동하지 않고 init --dir로 이전 위치를 지정할 수 있어요.

## 고정과 검증 순서

릴리스 준비 PR 병합 후 깨끗한 main SHA에서 최종 tarball을 한 번 만들어요. 같은 파일로 여섯 패키지 매니저의 격리 실행·타입·Vite·SSR과 공개 UI·하네스 다운로드, Next.js SSR·hydration을 확인해요. UI·하네스는 공개 파일 해시를 대조해 재사용하고 기존 태그·asset을 변경하지 않아요.

최종 tarball·SHA256SUMS·release.json은 cli-v0.3.1 Release에 제공할 예정이에요. npm 담당자는 [게시 안내](../npm-publishing.md)에 따라 검증한 파일만 게시해요. 이 준비 문서와 일반 PR 병합은 npm 게시 완료를 뜻하지 않아요.

실제 기기·화면 낭독기·에이전트 신뢰·스킬 수행·원격 MCP 검증은 자동 설치 검사와 구분해요. 최종 기록에는 실제 수행한 범위와 남은 제한을 함께 적어요.
