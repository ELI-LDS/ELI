# CLI 0.2.1 패치 후보

아직 npm에 게시하지 않았어요. PR #84의 하네스 전용 프로젝트 `status` 기본 출력 수정과 PR #85의 사용자용 README 정리를 포함해요. 공개 API·실행 의존성은 바꾸지 않아요.

고정 환경 frozen 설치와 `pnpm test:cli` 24개가 통과했어요. 같은 후보의 여섯 패키지 매니저 검사와 공개 UI 소비 검사는 진행 중이며 완료 후 전달 기록에 결과를 고정해요. 이전 후보의 검사 결과를 이번 파일의 결과로 대신하지 않아요.

## 게시 경계

준비 PR 병합 후 원본 SHA를 고정하고 검증한 동일 tarball·체크섬·공개 콘텐츠 주소·미확인 범위를 전달해요. npm 담당자는 [게시 안내](../npm-publishing.md)에 따라 파일 그대로 next에 게시하고 공개 명령 확인 후 latest로 전환해요. 이번 준비만으로 npm 게시를 수행하거나 기존 태그를 변경하지 않아요.

실제 Claude Code·Codex 스킬 수행, 사용자 훅 신뢰, 원격 MCP, 실제 모바일 기기·화면 낭독기 검증은 별도 범위예요.
