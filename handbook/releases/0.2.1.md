# CLI 0.2.1 패치 후보

아직 npm에 게시하지 않았어요. PR #84의 하네스 전용 프로젝트 `status` 기본 출력 수정과 PR #85의 사용자용 README 정리를 포함해요. 공개 API·실행 의존성은 바꾸지 않아요.

## 게시 경계

준비 PR #86을 병합한 `60e40b5477fd68541f590d33ae44cf8ef4573dfa`를 고정하고 [CLI 전달 Release](https://github.com/ELI-LDS/ELI/releases/tag/cli-v0.2.1)에 동일 tarball·체크섬·공개 콘텐츠 주소·미확인 범위를 제공했어요. npm에는 아직 게시하지 않았어요. npm 담당자는 [게시 안내](../npm-publishing.md)에 따라 파일 그대로 next에 게시하고 공개 명령 확인 후 latest로 전환해요. 이번 준비만으로 npm 게시를 수행하거나 기존 태그를 변경하지 않아요.

실제 Claude Code·Codex 스킬 수행, 사용자 훅 신뢰, 원격 MCP, 실제 모바일 기기·화면 낭독기 검증은 별도 범위예요.
