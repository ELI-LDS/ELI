# 아이콘 스타일

<!-- 맞춤: 이 파일은 초안이에요. {중괄호}는 프로젝트에 맞게 채우고, "맞춤" 주석의 지시대로 고친 뒤 주석을 모두 지워요. -->

이 문서는 {서비스 이름}의 커스텀 아이콘이 모두 같은 톤으로 나오게 하는 기준이에요. 아이콘을 만들기 전에 읽고, 만든 뒤에는 "만든 아이콘"에 추가해요.

## 언제 써요

커스텀 아이콘은 아껴 써요. 기본은 ELI의 선 아이콘이에요.

| 쓰는 자리 | 쓰지 않는 자리 |
| --- | --- |
| 빈 화면 | 버튼, 탭, 메뉴, 입력창 안 |
| 온보딩 | 라벨이나 문구 옆 |
| 완료·결과 화면 | 목록이나 카드처럼 반복되는 항목 |
| 오류 페이지 | 폼, 설정처럼 자주 들르는 화면 |
| 기능 소개 | 뜻 없이 빈 곳을 채우는 자리 |

- 한 화면에 커스텀 아이콘은 하나만 둬요.
- ELI의 선 아이콘을 크게 써도 뜻이 전달되면 그 아이콘을 써요.

## 형태

<!-- 맞춤: 원격 icon 가이드에 값이 있으면 그 값으로 바꿔요. 프로젝트에 이미 커스텀 아이콘이 있으면 그 아이콘에서 읽은 값으로 바꿔요. 둘 다 없으면 아래 기본값을 쓰고, 사용자에게 예시 아이콘을 보여준 뒤 확인받아요. -->

| 항목 | 값 | 설명 |
| --- | --- | --- |
| 캔버스 | `viewBox="0 0 96 96"` | 모든 아이콘이 같은 캔버스를 써요 |
| 안쪽 여백 | 사방 8 | 그림은 가운데 80 × 80 안에 그려요 |
| 그리는 방식 | 선 + 강조 면 하나 | 윤곽은 선으로, 가장 중요한 부분 하나만 면으로 채워요 |
| 선 굵기 | 4 | 모든 선이 같은 굵기예요. 크기를 바꿔도 굵기를 따로 바꾸지 않아요 |
| 선 끝 | 둥글게 (`stroke-linecap="round"`) | |
| 선이 만나는 곳 | 둥글게 (`stroke-linejoin="round"`) | |
| 모서리 반경 | 사각형은 8 | 뾰족한 모서리를 쓰지 않아요 |
| 좌표 | 정수나 0.5 단위 | 선이 흐려지지 않아요 |
| 도형 수 | 열 개 이하 | 더 필요하면 대상을 단순하게 바꿔요 |
| 시점 | 정면 | 원근과 입체를 쓰지 않아요 |

- 대상 하나만 그려요. 배경 장면, 사람, 여러 물건을 함께 그리지 않아요.
- 그림의 무게 중심을 캔버스 가운데에 맞춰요.
- 작은 크기로 줄여도 무엇인지 알아볼 수 있어야 해요.

## 색

<!-- 맞춤: 토큰 이름을 프로젝트 토큰 파일의 실제 이름으로 바꿔요. 토큰 파일이 없으면 /eli-design-system으로 먼저 만들어요. -->

한 아이콘에 색은 세 가지까지 써요. 색상 값을 직접 쓰지 않고 프로젝트 토큰을 써요.

| 역할 | 토큰 | 쓰는 곳 |
| --- | --- | --- |
| 선 | {예: `var(--color-text)`} 또는 `currentColor` | 윤곽선 전체 |
| 강조 | {예: `var(--color-brand)`} | 가장 중요한 면 하나 |
| 옅은 면 | {예: `var(--color-surface)`} | 강조 뒤의 넓은 면. 없어도 돼요 |

- 그라데이션, 그림자, 반투명 겹침을 쓰지 않아요.
- 밝은 배경과 어두운 배경에서 모두 보이는지 확인해요.
- 상태를 나타내는 색(성공, 경고, 오류)은 그 상태를 알리는 아이콘에만 써요.

## 크기

| 자리 | 표시 크기 |
| --- | --- |
| 빈 화면, 오류 페이지 | {예: 한 변 `6rem`} |
| 온보딩, 기능 소개 | {예: 한 변 `7.5rem`} |
| 완료·결과 화면 | {예: 한 변 `6rem`} |

- SVG에 고정 `width`와 `height`를 넣지 않아요. 크기는 쓰는 쪽에서 정해요.
- 단위는 `DESIGN.md`의 단위 기준을 따라요.

## 코드

- `viewBox`를 반드시 넣어요.
- 래스터 이미지, 외부 파일 참조, 글꼴에 의존하는 글자, 스크립트를 넣지 않아요.
- 쓰지 않는 그룹, 편집 도구가 남긴 속성, 빈 요소를 넣지 않아요.
- 장식이면 `aria-hidden="true"`를 넣어요. 뜻을 전달하면 `role="img"`와 이름을 넣어요.

## 만든 아이콘

같은 뜻의 아이콘을 다시 만들지 않아요. 비슷한 대상은 이미 만든 아이콘과 같은 모양으로 그려요.

| 이름 | 파일 | 나타내는 것 | 쓰는 화면 |
| --- | --- | --- | --- |
| {이름} | {경로} | {뜻} | {화면} |

## 스타일을 바꿀 때

선 굵기나 색 같은 스타일을 바꾸려면 아이콘 하나만 고치지 않아요. 이 문서를 먼저 고치고, 이미 만든 아이콘도 새 스타일로 다시 그려요.
