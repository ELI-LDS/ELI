# 설정 점검하기

ELI를 쓸 준비가 되었는지 확인해요. 읽기만 하고 아무것도 고치지 않아요. 코드가 디자인 시스템을 따르는지는 `/eli-verify`가 봐요.

## 1. 점검해요

각 항목의 결과는 네 가지 중 하나로 적어요.

| 결과 | 뜻 |
| --- | --- |
| 통과 | 확인했고 문제가 없어요 |
| 실패 | 확인했고 문제가 있어요 |
| 해당 없음 | 이 프로젝트에는 적용되지 않아요 |
| 확인 못함 | 확인할 방법이 없었어요 |

확인하지 못한 항목을 통과로 적지 않아요.

| 항목 | 확인하는 것 | 방법 |
| --- | --- | --- |
| 원격 연결 | `eli-docs` MCP에 연결되어 있는지 | `list_components`를 호출해요 |
| 설치 | `@eli-design/ui`가 `package.json`에 있고 실제로 설치되어 있는지 | `package.json`과 `node_modules/@eli-design/ui/package.json` |
| 버전 기록 | `DESIGN.md`의 `## 버전`이 실제로 설치된 `@eli-design/ui`·하네스(`eli` 스킬 폴더의 `VERSION`)와 같은지, 마지막으로 확인한 날짜가 14일 안인지 | `DESIGN.md`, `node_modules/@eli-design/ui/package.json` |
| 최신 버전 | 설치된 버전이 최신인지, 하네스가 서버의 최소 버전 이상인지 | `get_versions` |
| 버전 호환 | 설치된 React가 `@eli-design/ui`의 `peerDependencies`를 만족하는지 | 설치된 두 패키지의 `package.json` |
| React 중복 | React가 두 벌 설치되어 있지 않은지 | 패키지 매니저의 의존성 조회 명령 |
| 설치 방법 | 문서의 설치 단계를 모두 따랐는지, 문서에 없는 설정을 추가하지 않았는지 | `get_guide`의 `install` |
| 글꼴 | `DESIGN.md`의 `## 글꼴`에 적힌 글꼴을 전역 진입점에서 한 번 불러오는지, 글꼴 토큰과 `--eli-font-family-sans`가 그 글꼴을 가리키는지, 주 글꼴이 기본 글꼴이나 시스템 글꼴이 아닌지 | `DESIGN.md`, 진입점 파일, 토큰 파일 |
| 토큰 파일 | 프로젝트 토큰 파일이 있고 전역 진입점에서 불러오는지 | `DESIGN.md`의 `## 토큰`과 진입점 파일 |
| DESIGN.md | 있는지, `## 글꼴`과 `## 단위` 표가 있는지, `## 토큰`의 경로가 실제 파일과 맞는지 | 프로젝트 루트 |
| UX-WRITING.md | 화면 문구가 있는 프로젝트에 `UX-WRITING.md`가 있는지 | 프로젝트 루트 |
| ICON.md | 커스텀 아이콘이 있는 프로젝트에 `ICON.md`가 있는지 | 프로젝트 루트 |

- 원격 연결이 실패하면 원격 문서가 필요한 항목은 "확인 못함"으로 적고 나머지를 계속 점검해요.
- 모노레포면 `@eli-design/ui`를 쓰는 워크스페이스마다 따로 점검해요.
- 설치나 수정 명령을 실행하지 않아요.

## 2. 보고해요

```markdown
## 요약
통과 N, 실패 N, 해당 없음 N, 확인 못함 N

## 결과
| 항목 | 결과 | 근거 | 고치는 방법 |

## 다음에 할 일
```

- 근거에는 확인한 파일이나 명령을 적어요.
- 고치는 방법은 실패한 항목에만 적어요. 사용자가 그대로 따라 할 수 있게 구체적으로 적고, 맞는 명령이 있으면 함께 적어요.

## 3. 다음에 할 일을 안내해요

실패가 있으면 그것부터 고치자고 안내해요. 실패가 없으면 프로젝트의 상태에 맞는 명령을 하나만 권해요.

| 상태 | 권하는 명령 |
| --- | --- |
| 원격 연결이 안 되어 있어요 | `eli` 스킬의 연결 방법 |
| `DESIGN.md`, `UX-WRITING.md`, 토큰 파일이 모두 없어요 | `/eli-setup` |
| `DESIGN.md`만 없어요 | `/eli-design-md` |
| 토큰 파일이 없어요 | `/eli-design-system` |
| `UX-WRITING.md`가 없어요 | `/eli-ux-writing` |
| 새 버전이 있거나 확인한 지 14일이 지났어요 | `/eli-update` |
| 화면 코드가 이미 있어요 | `/eli-verify` |
| 모두 준비됐어요 | 만들고 싶은 화면을 말해 달라고 해요 |

사용자가 고쳐 달라고 하면 그때 고쳐요.
